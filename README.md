# Introduction to DevOps

## Overview and Concepts

Programming
- Software is programmed by developers
- Software is programmed in different programming languages e.g. Java, Python, JavaScript
- One developer team per application or per module
- This is where we introduce new functionalities
- Also, this is where we fix known bugs

Software Testing
- Software is being tested for its new features
- Also, being tested for old code/functionality
- Testing is done by the developers, also dedicated testers
- Testing nowadays is being done through automation

Software Release
- Build application (artifacts)
- Run the app on the server
- Upgrade existing software
- This is where IT Operations comes in, who are the ones handling running the software in production

#### Development vs Operations
After the Dev team release a new version of the software, the Ops team will deploy it in Production and handle the following:
- Manage downtime (sometimes, no downtime is expected)
- Handle huge traffic
- Making sure that the underlying infra is in good health and can handle the expected load
- Deployment requires configurations
  - environment variables
  - folder and files
  - permissions
- Environment preparation

**Skillset and toolset required**
- Dev team:
  - programming languages
  - test frameworks
  - databases
  - version control
- Ops team:
  - OS, mostly linux
  - command line
  - scripting
  - monitoring tools
