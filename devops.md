## Overview and Concepts

### Programming
- Software is programmed by developers
- In different programming languages
- One team per app or per feature
- New functionality
- Fix bugs

### Software Testing
- Test the new features
- Test the old code/functionality
- Testing is done by developers and dedicated testers
- Automated testing

### Operations (Release of Software)
- Building, package the application
- Run application on servers
- Upgrade existing software
- Run software in production
